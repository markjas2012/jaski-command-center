# Sprint 10.8 — Books / Reading Room

## Install
Copy these files into the matching locations in the Jaski Homepage project:

- `app/books/page.tsx`
- `components/BookRoom.tsx`
- `components/BookRoom.module.css`

Then apply the two small Sidebar changes in `SIDEBAR_PATCH.md`.

## Test before committing
1. Save all files.
2. Open `/books`.
3. Add a book to Reading Now.
4. Edit its progress.
5. Move it to Finished.
6. Refresh the browser and verify the book persists.
7. Verify all existing sidebar rooms still open.

Do not commit until the room and sidebar are verified.
