JASKI HOMEPAGE — SPRINT 13.12
PHISH POLISH

WHAT CHANGES
- Latest show card emphasizes venue, city, and full written date.
- Adds a compact show status/meta line.
- Setlist highlights expand to 10 songs in a denser two-column treatment.
- Songs are numbered for easier scanning.
- News can show up to 3 current stories.
- When news is sparse, official Tour Dates and LivePhish links fill the empty space.
- Keeps the #1 Grateful Dead / #2 Phish / #3 Widespread Panic hierarchy untouched.

INSTALL
1. Extract this ZIP.
2. Put/open the extracted sprint folder from C:\Projects\jaski-homepage.
3. EASIEST: double-click INSTALL_SPRINT_13_12.cmd

OR from the VS Code terminal at C:\Projects\jaski-homepage run:
  powershell -ExecutionPolicy Bypass -File <path-to-extracted-pack>\INSTALL_SPRINT_13_12.ps1

The installer creates a timestamped backup in _sprint_backups before replacing files.
