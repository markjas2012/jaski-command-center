JASKI HOMEPAGE — SPRINT 11.8
FEATURED TODAY — SOURCE QUALITY

Goal
----
Keep the exact three-card Featured Today design, but improve where the cards
come from.

What changes
------------
- Boosts stronger sources such as Reuters, AP, ESPN, PGA Tour, Variety,
  Deadline, The Hollywood Reporter, JamBase, Relix, IGN, Engadget, The Verge,
  Polygon, and similar sources.
- Downranks low-value aggregation/shopping-style sources.
- Keeps freshness scoring.
- Keeps duplicate-topic filtering.
- Keeps the daily Explore rotation.
- No UI changes.
- No Sidebar changes.
- No homepage layout changes.

Install
-------
Extract this ZIP into:

C:\Projects\jaski-homepage

Allow replacement of:

app\api\featured-today\route.ts

No PowerShell command.

Then hard refresh the homepage with Ctrl + Shift + R.

quality, not a design change.
