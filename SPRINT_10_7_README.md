# Sprint 10.7 — Video Games

## What this adds
- `/games` Video Games room
- Playing Now tracker
- Play Next short backlog
- Editable game title, platform, and progress/note
- Move games between Playing Now, Play Next, and Finished
- Replay / remove finished games
- Browser localStorage persistence
- Reserved "Worth Knowing About" area for future releases and subscription additions

## Install
1. Copy `app/games` into your project's `app` folder.
2. Copy `components/GameRoom.tsx` and `components/GameRoom.module.css` into `components`.
3. Follow `SIDEBAR_PATCH.md` to wire the existing Video Games sidebar item to `/games`.
4. Save.
5. Refresh `localhost:3000/games`.

Do not commit until the room and sidebar link are tested.
