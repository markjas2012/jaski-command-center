# Sprint 10.5 — Movies + Streaming Room

Purpose: make Movies a "What should I watch?" room, with streaming as the priority.

Adds:
- /movies
- Streaming-first hero

Install: extract into C:\Projects\jaski-homepage and allow Windows to merge/replace files.

Test: open http://localhost:3000/movies and click Movies from the sidebar.
