# Sprint 10.6 — TV Shows

Adds a persistent personal TV tracker at /tv.

Features:
- Currently Watching
- + Add Show
- Service, season, episode
- "Watched" advances to the next episode
- Finished moves a show to Recently Finished
- Resume and Remove
- Up Next
- New This Week placeholder for a future live content feed
- Browser localStorage persistence
- TV Shows sidebar route + active state

No global CSS is replaced.

Install into C:\Projects\jaski-homepage, merge folders, and allow Sidebar.tsx to replace.
Then open /tv or click TV Shows.
