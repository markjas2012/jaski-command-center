# Sprint 10.6.1 — TV Edit Hotfix

Adds Edit to Currently Watching cards.

IMPORTANT: Copy TVRoom.tsx into components.

Then append the contents of TVRoom.hotfix.css to the END of components/TVRoom.module.css.
Do not replace TVRoom.module.css with the hotfix CSS file.

Edit allows:
- Show title
- Streaming service
- Season
- Episode
- Save / Cancel

Existing localStorage data is preserved.
